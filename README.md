# けいさんカード ＆ けいさんクエスト

小学校1年生向けの「けいさんカード」をスマートフォン・PCで使える Web アプリです。  
ちびむすドリル【大サイズ】の計算カード4種類に準拠したフラッシュカード練習と、ランダムダンジョン探索アクションRPG「けいさんクエスト」を遊べます。

**[アプリをひらく（GitHub Pages）](https://beagleworks.github.io/keisanapp/)**

## 主な機能

### けいさんカード練習モード
- 4種類のカードセット（ちびむすドリル【大サイズ】準拠・全162問）
  - **たしざん 1**：10までのたしざん（45枚） — [ちびむすドリル](https://happylilac.net/kazu-tasizancard.html)
  - **たしざん 2**：くりあがりのあるたしざん（36枚） — [ちびむすドリル](https://happylilac.net/mu202007151250.html)
  - **ひきざん 1**：10までのひきざん（45枚） — [ちびむすドリル](https://happylilac.net/kazu-hikizancard.html)
  - **ひきざん 2**：くりさがりのあるひきざん（36枚） — [ちびむすドリル](https://happylilac.net/mu202007151311.html)
- 毎回ランダム出題、タイム計測・ベストタイム保存、もんだい一覧表示に対応

### ゲームモード「けいさんクエスト」
- 単元別4ステージ＋全162問ミックスの総合問題5面の全5ステージ構成
- 遊ぶたびにマップ・ルート・敵や宝箱の配置が変わるランダムダンジョン
- ハイスコア＆ランク（S / A / B / C）評価、進捗リセット・マップやり直しに対応
- PC（キーボード）・スマートフォン（タッチ操作）両対応
