# けいさんカード ＆ けいさんクエスト

小学校1年生向けの「けいさんカード」をスマートフォン・PCで代用できる Web アプリです。  
ちびむすドリル【大サイズ】の計算カード4種類に準拠したフラッシュカード練習と、初代ゼルダ風のトップダウンアクションRPG「けいさんクエスト」を遊べます。

## 主な機能

### 1. けいさんカード練習モード
- **4種類のカードセット（ちびむすドリル【大サイズ】準拠）**
  - **たしざん 1**：10までのたしざん（45枚） — [ちびむすドリル](https://happylilac.net/kazu-tasizancard.html)
  - **たしざん 2**：くりあがりのあるたしざん（36枚） — [ちびむすドリル](https://happylilac.net/mu202007151250.html)
  - **ひきざん 1**：10までのひきざん（45枚） — [ちびむすドリル](https://happylilac.net/kazu-hikizancard.html)
  - **ひきざん 2**：くりさがりのあるひきざん（36枚） — [ちびむすドリル](https://happylilac.net/mu202007151311.html)
- **毎回ランダム出題**（Fisher-Yates シャッフル）
- **タイム計測 ＆ ベストタイム保存**（ブラウザの `localStorage` に自動保存）
- **かんたん操作**：開始後に問題表示 → クリック／タップ／スペースキーで答え表示 → クリック／タップ／スペースキーで次の問題へ
- **もんだい一覧モーダル**：各カードセットの全問題を確認可能

### 2. ゲームモード「けいさんクエスト」（初代ゼルダ風アクションRPG）
- 4つのカードセットそれぞれに対応した **4つの神殿（全6部屋構成）** を探索
  - みどりの もり（たしざん1）／あかい かざん（たしざん2）／みずの しんでん（ひきざん1）／ほしの だんじょん（ひきざん2）
- モンスターとのバトルや宝箱を開けるたびに4択の計算問題に挑戦
- 連続正解コンボ・早解きボーナス・先制こうげきボーナスで得点を稼ぎ、カギを見つけてボスを3回正解で撃破！
- **PC・スマホ両対応**：PCは矢印キー / WASD + スペースキー + 1〜4キー、スマホは画面下の十字キー＆「けん」ボタンで操作可能

## 開発コマンド

```bash
pnpm install
pnpm dev       # 開発サーバー起動
pnpm test      # 単体テスト実行（Vitest）
pnpm build     # 本番ビルド（dist/ に出力）
pnpm preview   # 本番ビルドのプレビュー
```

## GitHub Pages へのデプロイ

静的サイト（Vite + React + TypeScript）として構成されており、`.github/workflows/deploy.yml` により GitHub Actions から GitHub Pages へ自動デプロイできます。

1. このリポジトリの `main` ブランチへマージする
2. GitHub リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定する
3. `main` へのプッシュ（または Actions タブからの手動実行）で自動的に公開されます
